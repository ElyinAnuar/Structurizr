# Datos de RedEfectiva

## Modelo de datos inicial

El almacenamiento inicial puede centrarse en la persistencia de la información operativa y transaccional de la plataforma.

## Consideraciones

- Definir entidades principales del negocio.
- Identificar los datos que maneja cliente, operador y sistema.
- Determinar reglas de acceso, auditoría y retención.

> Este documento debe completarse con el diseño final del modelo de datos.
