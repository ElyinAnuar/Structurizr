# Arquitectura de software de RedEfectiva

## Vista de componentes

La solución inicial contempla una estructura simple basada en:

- Aplicación web
- API principal
- Base de datos
- Actores del sistema: cliente y operador

## Principios

- Separación clara entre exposición, lógica de negocio y persistencia.
- Visibilidad de las relaciones principales entre actores y componentes.
- Base extensible para evolucionar hacia mayor detalle funcional y técnico.
