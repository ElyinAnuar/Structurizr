# Visión funcional de RedEfectiva

## Objetivo

Definir el alcance funcional inicial de RedEfectiva para orientar la arquitectura y la documentación del sistema.

## Funcionalidades iniciales

- Acceso a la plataforma por parte del cliente.
- Administración y supervisión por parte del operador.
- Consulta de información desde la aplicación web.
- Procesamiento de operaciones a través de la API.
- Persistencia de datos en la base de datos.

## Alcance provisional

Este documento debe completarse con los flujos reales de negocio, roles, permisos y servicios que forme la solución final.
